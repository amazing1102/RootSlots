# CET-4 词表 · 「前缀 + 词根 + 后缀」三段式构词整合

> 标准:单词须能干净拆成「前缀 + 词根 + 后缀」三部分(或含三部分的多段词)。
> 因此 dictation(dict+ation,无前缀)、satisfaction(根+根+缀,无前缀)、reaction? ✓有前缀——逐一甄别后收录,共约 230 词。
> 连写规则:ac-/af-/ag-/ap-/ar-/as-/at- = ad-;col-/cor- = com-;dif- = dis-;ec-/ef- = ex-;ig-/i- = in-;op-/oc- = ob-;suc-/suf-/sus- = sub-;intel- = inter-;ag-/al-/an- 等。
> 连接元音:-o-/-i-(如 agriculture, stupidity);-ul-/-it- 等(如 congratulate, prejudice)。

## 四、拆解小贴士

1. **同化前缀**:ad-/com-/in-/ob-/sub-/ex- 接不同首字母会变形(accord, collaborate, irregular, occur, succeed, effect)——先还原成基本形再拆。
2. **双词根词**:satisfaction = satis(满)+fact(做)+ion;manufacture = manu(手)+fact(做)+ure;biotechnology = bio+techn+o+logy——这类是「根+根+缀」,不算三段式,但同属词根法。
3. **连接字母**:-o-(astr-o-nomy)、-i-(uni-ty? 无;如 fugit-ive 类)、-ul-(grat-ul-ation)、-it-(fin-it-e)不承担词义。
4. 拉丁词层才有系统构词;本表 core 词(water, take, look)不适用。
